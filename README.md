# Solve Tree Problems

A Python project for solving popular binary tree DSA problems.

## Structure
- `src/tree/`: Core tree classes
- `src/problems/`: DSA problem solutions
- `tests/`: Unit tests

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `pytest`

## Bootstrap
Includes basic `TreeNode` and `BinaryTree` classes. Add your solutions in `src/problems/`.
